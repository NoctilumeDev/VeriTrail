# VeriTrail 0.12.1 Release Notes

VeriTrail 0.12.1 是 Core 0.12.0 之后的有界维护版。它只修复一个公开入口合同缺口：只安装 wheel、
没有 Git checkout 的用户现在也能完成一条自包含、可验证的 Core 首跑。

它不重开 M0–M14，不改变 Plan、Evidence、Verdict、Bundle、Comparison、Pairing 或 Batch 语义，
也不移动或改写 `v0.12.0`。

包元数据同时移除已经过期的 `Pre-Alpha` 分类，将公开成熟度与当前有界稳定状态对齐为 `Beta`，并
补齐已由公共 CI 实测的 Python 3.13 分类器；这只是发布元数据校正，不扩张运行时能力边界。

## 新增：无 checkout 合成首跑

安装 `veritrail-0.12.1-py3-none-any.whl` 后运行：

```powershell
veritrail demo --output artifacts\first-run-demo
```

命令只使用 wheel 内置常量，生成：

- 一份 sealed 合成 Plan；
- 同 Plan digest 的一个 `PASS` Bundle 和一个故意 `FAIL` Bundle；
- 收录两个 Run、issue 为零的只读 Catalog；
- 边界标记为 `SYNTHETIC_CORE_DEMO_NOT_PROJECT_ACCEPTANCE` 的摘要。

输出目录必须是新路径。命令在同一父目录 staging 后原子发布，不覆盖既有目录，失败时不暴露半成品，
也不把本机绝对路径写入 JSON 或 Markdown。

## 这条命令不做什么

`demo` 不探测用户项目，不推断启动命令、端口、健康检查或验收断言，不批准 Starter 草案，不运行
外部项目，也不能把合成 `PASS` 描述成用户项目已经通过验收。Starter 与 Authoring Skill 仍只能
生成 `DRAFT / NOT_SEALED / NOT_RUN / NO_VERDICT`。

## 验证矩阵

维护候选已经通过：

| 门禁 | 结果 |
| --- | --- |
| Core Python 3.10 普通／`-O` | `340/340` + `340/340` |
| Core Python 3.13 普通／`-O` | `340/340` + `340/340` |
| Starter 双 Python 普通／`-O` | 每组 `24/24` |
| Authoring Skill 双 Python 普通／`-O` | 每组 `24/24` |
| Workbench | `172/172`、lint、type-check、生产构建、依赖审计 |
| GitHub 无 checkout wheel-only | Python 3.10／3.13 均通过 |
| 本机仓库外 clean venv | Python 3.10.6／3.13.13 均通过 |

公开 CI 先在正常 job 构建 wheel，再让两个没有 checkout、workspace 为空的 Windows job 只下载并
安装该 wheel，验证 PASS／故意 FAIL、同 Plan、Catalog、边界标记与无 runner 路径泄漏。

## 仓库治理

- `main` 禁止删除和 force-push；
- 所有变更必须经过 Pull Request；
- 七项实际 CI context 被设为严格必需检查；
- 单维护者规则不要求无法完成的自我批准；
- `v*` Core 稳定标签禁止删除和改写。

## Release 资产

```text
veritrail-0.12.1-py3-none-any.whl
veritrail-0.12.1.tar.gz
veritrail-workbench-0.12.1.zip
core-v0.12.1-validation-summary.json
SHA256SUMS.txt
```

`SHA256SUMS.txt` 采用非自指约定，覆盖其余四个 payload；它自身由上传副本与公开下载副本逐字节
比较。Release 发布后还必须再次在仓库外只安装公开 wheel，运行 `veritrail demo` 并核对 Release
target、标签、资产大小、GitHub digest、下载 digest 与事实文档。该读回完成前，不得把候选构建
冒充稳定发布事实。

完整变更边界和停止线见
[Core 无 checkout 首跑维护合同](71-core-first-run-maintenance-contract.md)。
