VeriTrail 0.12.3 是从不可移动 `v0.12.2^{}` 谱系建立的有界维护候选。它只把已经在 current source
独立取得资格的 Browser 主机 socket 分类修正回移到受保护的 `core-0.12-maintenance` 分支；相同补丁与相同
终态不让 maintenance 继承 current-main 的 source、attempt、release 或 public-readback authority。

## 唯一生产语义变化

Browser request-failure collector 取得既有 raw failure text 后，只有：

```text
raw_failure_text.strip() == "net::ERR_NO_BUFFER_SPACE"
```

才增加 private collector projection：

```text
collector  = network:<viewport>
error_type = HostSocketNoBufferSpace
```

原始 Network record 的 `failure` 保持不变。这个精确世界必须形成
`COLLECTOR_ERROR / ERROR / PENDING`，不能继续被归给 Subject；大小写变化、前后缀、
`ERR_CONNECTION_RESET`、`ERR_INSUFFICIENT_RESOURCES`、未知或空 failure 都不是这个分类。
真实 selector、fill、click 或业务断言失败继续保持既有
`BROWSER_HARD_FAILURE / COMPLETED / FAIL`。

本修正不增加 retry，不扩大 timeout，不忽略 Network failure，也不改变 Plan、Evidence、Catalog、
Workbench、Starter 或 Authoring Skill 的公共合同。

## 候选验证边界

合入 `core-0.12-maintenance` 前，候选必须完成：

- CPython 3.10 / 3.13 normal 与 `-O` 的完整 Core、Starter 和 Authoring Skill 回归；
- exact failure、near-miss、raw Network fact、两类 viewport collector identity 与 exactly-once projection；
- deterministic bootstrap/CLI world 的 `COLLECTOR_ERROR / ERROR / PENDING`；
- 既有 selector/business failure 的 `BROWSER_HARD_FAILURE / COMPLETED / FAIL`；
- wheel 与 sdist 的 checkout-free clean install；
- 未修改的公开 Starter 0.2.0 wheel compatibility、doctor 与真实 PASS/故意 FAIL 链；
- Catalog、Workbench、Browser、端口、进程、SQLite sidecar、owned staging 与敏感路径门；
- original PR required checks、受保护合入，以及新 maintenance exact-tip Public CI / Browser Smoke。

候选中的 `scripts/core_0123_release_probe.py` 只提供 installed-distribution 的精确分类验证入口；它不创建
tag、Release、公开资产或最终 validation summary，也不替代上述门。

## 计划公开资产

只有候选合入且新的 maintenance exact tip 双门成功后，M2 才能从 clean detached checkout 重新构建：

```text
veritrail-0.12.3-py3-none-any.whl
veritrail-0.12.3.tar.gz
core-v0.12.3-validation-summary.json
SHA256SUMS.txt
```

0.12.3 不重新分发未变化的 Workbench ZIP。`SHA256SUMS.txt` 使用非自指约定，只覆盖前三个 payload；
其自身只能由 final staging、GitHub asset digest 与匿名下载字节核账。目标 Release 必须是 non-Latest、
non-prerelease；当前 Latest `v0.13.0` 保持不变。
