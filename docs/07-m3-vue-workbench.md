# 07. M3 Vue 证据工作台

## 状态

`PLANNED（验收合同已冻结）`。M0、M1、M2 已分别达到 `FROZEN`，因此 M3 可以在本合同
进入主分支后开始实现。当前状态只表示问题、范围、设计语言和退出条件已经预注册，不表示
Vue、SQLite、本地 API 或自举闭环已经实现。

若实现需要修改 Report 0.1、Evidence 0.1、Plan 0.1–0.3、`browser.session`、Verdict 优先级
或证据清单语义，必须停止 M3，实现范围升级为新的 `L2_CONTRACT` 变更并重新冻结消费者矩阵。

## 目标问题

M3 只回答：

> VeriTrail 能否在不重新裁决、不上传数据和不改变 M0–M2 契约的前提下，用一个资源有界、
> 可访问的 Vue 工作台读取真实证据包，使用户从同一页面看懂运行状态、验收结论、控制变量、
> 断言、证据、浏览器事实、完整性和适用边界？

M3 是“读取同一裁决结果”的最小用户纵向切片，不是完整 v0 自举。它不执行项目命令，不启动
被测对象，不编辑计划，不写 SQLite，也不宣称已经完成跨 Run 比较、批次编排或报告发布。

## 影响层级、所有者与消费者

- 声明层级：`L2_CONTRACT`；故宫主题本身是 `L0_PRESENTATION`，但工作台首次消费公共报告与
  证据结构，使里程碑整体按较高层级审查；
- 所有者：Vue Workbench；
- 只读输入：Report 0.1、Evidence Manifest 0.1、Bundle Manifest 0.1、Evidence 0.1、
  `runtime.preflight`、`browser.session` 和 M2 PNG 附件；
- 直接消费者：工作台运行时校验器、Bundle Loader、视图模型、断言/证据/浏览器视图和测试；
- 后续消费者：轻量前端自举、SQLite 索引、本地 API、跨 Run 比较和多 Context 浏览器能力；
- 保持不变：Python Core、现有 Schema、确定性裁决、Plan 哈希、M0–M2 CLI、证据生成和脱敏规则。

如果实际 diff 触及 `src/veritrail/`、`schemas/` 或 M0–M2 示例计划，先按范围漂移处理；不能以
“只是为了前端好用”为理由改变冻结的生产者契约。

## 控制变量设计

M3 自身的正/负显示验收采用一个主要变量：

```text
PRIMARY: loaded_evidence_bundle = positive | negative | invalid
```

以下保持受控：同一 Workbench 构建物、浏览器版本、服务 origin、视口、交互步骤、主题令牌、
组件树、Bundle Loader、运行时校验规则和资源预算。正向与负向证据使用相同输入契约；UI 必须
逐字展示源报告的 `execution_status` 与 `verdict`，不得根据颜色、断言计数或浏览器错误自行改写。

`invalid` 只验证工作台的失败边界，不参与被测项目的业务 Verdict。无法解析或完整性失败的包
标记为“证据包不可读取/完整性未通过”，不能伪造成该 Run 的 `FAIL`、`INCONCLUSIVE` 或
`PENDING`。

## M3 功能边界

### 必须包含

1. 使用 Vue 3、TypeScript 和 Vite 建立 `web/`，提交锁文件并声明 Node 引擎；本机实现基线使用
   Node 24.14.0，最低兼容条件遵循官方 Vue/Vite 当前要求 `^20.19.0 || >=22.12.0`，明确拒绝
   本机旧 Node 18；
2. 提供两个输入入口：仓库内脱敏确定性演示包，以及 Chromium 桌面端本地目录选择；本地文件
   只在浏览器内存中读取，不上传、不写回、不自动持久化；
3. 读取并运行时校验 `report.json`、`evidence-manifest.json`、`bundle-manifest.json`、被引用的
   Evidence JSON 与受支持附件；对字段缺失、未知版本、非法相对路径、重复路径、大小/数量越界、
   哈希不符和引用缺失给出可恢复错误；
4. 使用 Web Crypto 逐文件核对 Bundle Manifest SHA-256。完整性校验只回答文件是否匹配清单，
   不参与 Verdict；
5. 分开显示 ExecutionStatus 与 Verdict，并展示原因、Plan ID/版本/哈希、Baseline、唯一主要变量、
   负载语义、资源预算、ChangeScope、缺失证据、污染、复现和清理步骤；
6. 提供断言筛选与证据索引；浏览器证据至少能查看视口、步骤、Console、页面异常、Network、
   截图、横向溢出、采集完整性和清理状态；
7. Report 0.1 中不存在浏览器证据时显示明确的“不适用/未包含”，而不是报错或伪造空通过；
8. Bundle 切换、错误恢复、刷新和浏览器返回后保持可理解状态；对象 URL 在切换和卸载时释放；
9. 桌面与移动端均能完成核心阅读链路，支持键盘、清晰焦点、语义化结构和非颜色状态提示；
10. 所有运行时请求保持同源回环；生产构建不依赖 CDN、远程字体、统计脚本或第三方图片。

### 明确不做

- 计划编辑、Seal、Preflight、Browser Capture、任意命令执行或服务生命周期管理；
- 在浏览器端复制 Verdict 规则，或允许用户手工把 Verdict 改为其他值；
- SQLite、本地 API、账号、同步、云上传、协作、权限或发布托管；
- 跨 Run 差异算法、组合矩阵编辑、实时资源图、通知和 AI 解释；
- HTML/Markdown 富文本执行、远程 URL 导入、HAR 正文展示或认证材料展示；
- 暗色模式、大面积背景图、复杂动效、龙纹/宫殿照片堆叠和最终公开演示包装。

## Bundle Loader 与安全边界

- 目录入口只接受普通文件映射；规范化后路径必须留在所选根目录，拒绝绝对路径、驱动器前缀、
  `..`、反斜杠混淆、NUL、重复规范路径和未声明附件；
- 默认上限为 256 个文件、单文件 10 MiB、整包 64 MiB；达到上限直接拒绝，不部分读取后继续显示；
- JSON 作为数据解析，Markdown 作为纯文本；禁止 `v-html`、动态脚本、动态组件名和不可信 SVG；
- M3 附件只展示清单中通过哈希检查的 PNG/JPEG，使用受控 `Blob` URL，并在不再需要时撤销；
- 演示包 fetch 只允许编译时声明的同源相对路径；用户输入不能构造任意网络 URL；
- 错误消息不得回显用户绝对路径、查询值、Cookie、认证头或原始敏感字段；
- 前端校验失败不能修改或覆盖原证据。Loader 只产生独立的 UI 诊断，不把诊断写回报告；
- 浏览器缓存、Service Worker 和遥测不属于 M3；刷新后需要用户重新选择的本地目录是预期隐私边界。

## 信息架构

M3 使用一页式“证据院落”，不引入路由层级和全局状态库：

1. **门额 / Run Header**：产品名、证据包来源、运行状态、验收结论和完整性；
2. **前朝 / Overview**：原因、Plan/Baseline、主要变量、适用边界和资源预算；
3. **中庭 / Assertions**：按状态与严重性筛选的断言，显示 expected、actual 和证据引用；
4. **东庑 / Evidence Ledger**：Evidence 清单、哈希、大小、脱敏与解析器版本；
5. **西庑 / Browser Evidence**：步骤、Console、Network、视口、截图和采集/清理事实；
6. **后寝 / Reproduce & Clean**：缺口、污染、复现步骤、清理步骤与报告元数据。

这些名称只用于设计说明；界面文案优先使用清晰的工程术语，不要求用户理解宫殿礼制才能导航。
桌面端以中轴网格组织，移动端按上述证据优先级单列排列；断言表在移动端转为卡片，页面本身
不得产生横向溢出。

## 故宫色彩主题合同

主题名为 **“宫阙验迹 / Palace Evidence”**。它借鉴紫禁城红墙黄瓦、汉白玉台基、青砖、
青绿彩画以及轴线与院落秩序，但不是古建修复色卡，也不使用故宫博物院标志、藏品照片或官方
视觉资产。

### 基础令牌

| 角色 | 名称 | 建议初值 | 使用边界 |
| --- | --- | --- | --- |
| 页面底色 | 宣纸白 | `#F5EFE3` | 大面积背景 |
| 内容底色 | 玉阶白 | `#FFFBF3` | 卡片与阅读面 |
| 主文字 | 墨黑 | `#241B17` | 正文、数据与标题 |
| 严重异常色 | 宫墙朱 | `#8D1B1B` | 只用于 FAIL、ERROR、异常告警和故障断点 |
| 活跃强调 | 琉璃金 | `#B58A32` | RUNNING、校验中和受控进度；不单独承载小号文字 |
| 深色结构 | 黛青 | `#173F4F` | 导航、代码/哈希面与高对比结构 |
| 次级结构 | 青砖灰 | `#6B655D` | 辅助文字与边界 |

最终实现可在无障碍测试中微调数值，但不得改变语义角色。整体比例以玉白/宣纸白为主，墨与
黛青承担信息层级，琉璃金只作克制的活跃提示；正常静止界面不以朱红装饰，不使用金色渐变
制造“奢华感”。

### 状态语义

- `PASS` 使用玉石绿；`FAIL` 使用宫墙朱；`INCONCLUSIVE` 使用石青；`PENDING` 使用青砖灰；
  `RUNNING` 使用琉璃金；`ABORTED` 使用炭灰；`ERROR` 使用朱红警示边框；
- 宫墙朱不得用于普通按钮、导航、选中、高亮或纯装饰。它只表达严重失败、执行错误、异常告警
  和故障断点；每个状态仍须同时具备文字、图标/形状和可读标签，不能只靠颜色；
- ExecutionStatus 与 Verdict 使用不同组件和标题，即使组合为 `ABORTED + PENDING` 也不能
  压缩成一个徽章；
- 正文和交互文字至少满足 WCAG AA：普通文本对比度 4.5:1，大字及非文本交互边界 3:1；
- 焦点环、错误提示、选中状态和图表说明都不能仅依赖红/绿差异。

### 字体、纹理与动效

- 中文标题使用本机宋体风格回退栈，正文使用系统无衬线，哈希与结构化数据使用本机等宽字体；
- 不下载网络字体。字体回退不能改变信息或导致布局遮挡；
- “中轴、院落、格栅”只用 CSS 几何、留白和细边框抽象表达，不复制传统纹样或官方资产；
- 动效只用于 150 ms 左右的焦点、展开和切换反馈；`prefers-reduced-motion` 下关闭非必要动效；
- 交互目标至少 44×44 CSS px，截图放大层可用键盘关闭并把焦点归还触发元素。

M3 建立的是可长期复用的设计令牌和信息秩序。路线图末尾的视觉收尾可以优化细节与演示质感，
但不得在美化阶段顺手改变状态语义、证据层级、数据契约或用户验收流程。

## 自动化验收矩阵

- `npm ci` 只使用锁定依赖；生产依赖和构建产物不包含远程 CDN 请求；
- TypeScript、Vue SFC 类型检查、生产构建和 lint 通过；Vite 构建不能代替浏览器验收；
- 单元/组件测试覆盖 Report 0.1 运行时校验、ExecutionStatus/Verdict 分离、未知版本、路径穿越、
  重复路径、数量/大小停止线、哈希不符、缺失引用、无浏览器证据和对象 URL 清理；
- 正/负/非法三个夹具只改变 `loaded_evidence_bundle`，相同构建和步骤得到可重复 UI 状态；
- PASS、FAIL、INCONCLUSIVE、PENDING 及 ABORTED 组合全部有非颜色语义和可访问名称；
- 键盘焦点顺序、筛选、标签页、错误重试、截图放大与关闭有组件级回归；
- 测试 worker 上限为 2，不启用无界并行；
- Python 3.10 与 3.13 的 M0–M2 冻结回归、Plan 哈希和 CLI 行为保持不变；
- 仓库只提交经过脱敏的最小夹具；构建目录、浏览器 trace/HAR、截图和运行证据继续忽略。

## 真实运行退出条件

在干净提交和当前 16 GB Windows 主机上串行执行：

1. 运行 M1 资源预检；只启动一个回环 Vite/静态服务器和一个浏览器，不使用 Docker；
2. 使用生产构建读取一份真实 M2 正向证据包，确认 `COMPLETED + PASS`、Plan/Baseline、断言、
   Evidence、Console、Network、双视口截图、完整性和清理事实均可追溯到源文件；
3. 只切换输入包，读取真实 M2 负向证据，确认 `COMPLETED + FAIL` 以及 Console、页面异常和
   HTTP 404 不被隐藏，且 UI 没有自行重新裁决；
4. 导入未知版本、哈希不符或缺失引用的非法包，确认错误有边界、无部分可信展示，并可返回
   有效包重试；
5. 使用真实 Chromium 自动化完成演示包选择、本地目录导入、状态筛选、浏览器证据标签、截图
   放大、失败重试、刷新/返回和桌面/移动视口；
6. 使用 Codex 内置浏览器在桌面和移动关键视口再次完成用户链路，检查 DevTools Console、
   Network、请求来源/状态/重试、未解释 4xx/5xx、外部请求和页面横向溢出；
7. 键盘完成核心导航，检查可访问名称、焦点可见、状态非颜色表达、对比度和减少动效；
8. 核对本地文件未上传、敏感扫描 0 命中、演示夹具与清单哈希一致；
9. Python 3.10/3.13 与前端自动化全部通过，M0–M2 已知哈希不变；
10. 结束后 Vite/静态服务器、浏览器、端口、临时目录和对象 URL 均释放，Git 工作区只包含
    预期提交；冻结提交与 `m3-v0.4.0` 标签可从 GitHub 读回。

只有以上全部成立，M3 才能依次推进到 `IMPLEMENTED`、`AUTOMATED`、`RUNTIME_VALIDATED` 和
`FROZEN`。任何一项未执行时，只能报告实际阶段；不能用故宫主题完成、组件测试绿色或构建成功
替代工作台真实链路闭环。
