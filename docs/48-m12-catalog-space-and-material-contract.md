## 1. 触发事实与唯一变量

用户在真实生产浏览器中否决了此前的素材接入候选。问题不是素材本身，而是旧页面仍保留
“标题卡 -> 工具卡 -> 目录卡”的空间结构，再把金瓦、水纹和框饰直接压在每层表面。
结果是贴图感、重复屋檐和卡片层叠，而不是由证据关系决定的院落与账册。

本合同只改变下一段前端施工方法：

```text
catalog_presentation_method = skeleton_first + bounded_material_components
```

它不改变 M0-M11 的 Schema、Bundle/Manifest 校验、Catalog/API、Verdict、URL/history、文件导入、
`data-testid`、键盘契约、焦点恢复、只读边界或浏览器证据语义。当前工作树中的任何试验性 CSS 不是
本合同的完成事实，也不能据此冻结 M12。

## 2. 先于材质的空间骨架

在引入金瓦、纹理或装饰图之前，Catalog 必须先以真实 M11 Run 数据成立如下阅读顺序：

```text
全宽深青顶栏
    -> 小型中轴过渡
    -> 四项公共视图导航
    -> 页面标题 + 真实来源操作轨
    -> 深青目录题签
    -> 连续 Run 账册
```

桌面基准是 `1440x960`，使用长 Run ID、`PASS / FAIL / ABORTED + PENDING`、四个目录列和真实本地导入。
移动端不是缩小桌面，而是在相同语义顺序下将三个示例按钮与本地导入操作重新排布。

### 2.1 边界预算

每一个可见事实最多拥有一层结构边界。以下预算是硬约束：

| 层级 | 允许的空间表达 | 明确禁止 |
| --- | --- | --- |
| 全页纸面 | 连续纸张底色与排版留白 | 页面四周再套一张装饰框 |
| Masthead | 一座全宽深青厅堂 | 厅堂内部再嵌独立卡片框 |
| 公共导航 | 无框的四个入口与一条低对比过渡 | 入口外再包一层导航卡 |
| 来源操作轨 | 一条分段操作带，导入是唯一主操作 | 工具条外框 + 檐口 + 内部按钮框三层叠加 |
| Catalog | 一个深青题签接连续账册 | “目录卡”外框再包每条 Run 卡 |
| Run 行 | 细分隔线、左侧事实标记、紧凑状态铭牌 | 行容器、状态、字段同时拥有独立卡片底色 |

“有装饰”不构成增加边界的理由。长 Hash、失败状态、文件导入命中区、焦点环和表格列优先于任何翘角、
金线或图案。

## 3. 素材职责表

用户提供的本地生成素材只可按下表承担唯一职责。它们不是页面截图，也不能作为整页背景、假数据或
无行为控件。

| 素材族 | 唯一职责 | 适配方式 | 禁用位置 |
| --- | --- | --- | --- |
| 暖白宣纸 | 全页和连续账册的物理底面 | 固定比例平铺或低透明度叠色；不得产生可见网格接缝 | 状态标签、按钮文字下的对比关键区 |
| 深青漆纹 | Masthead 与 Catalog 题签的连续底材 | 先从无边饰中心取得可平铺材质；边饰不随容器拉伸 | 每个 SectionFrame、每条 Run 行 |
| 中轴金饰 | Masthead 与导航之间的一次过渡 | 以原比例居中显示；不可被裁切或重复 | 工具条、账册行、状态标签 |
| 云水纹 | 四项公共导航之后的低对比过渡 | 透明边界裁净后单次显示，文字与焦点环上方留出净区 | 运行状态、表格背景、Pairing 的因果箭头 |
| 四枚导航图标 | Pairing / Runs / Batch / Comparison 的固定入口识别 | 裁去透明留白后作为 `alt=""` 的装饰图；名称仍由按钮文本提供 | Verdict、Execution status、普通操作按钮 |
| 金砖金瓦 | 一个经过验证的一级门槛 | 必须先拆为左端、中段、右端三段；中段只能 repeat-x，端部不得拉伸 | 工具轨与 Catalog 题签同时重复出现；小卡片顶边 |
| 朱红操作面 | 唯一真实“选择本地证据包”入口 | 必须先拆为九宫格或左右端 + 中间填充；保留原生 `label/input` 命中区 | FAIL/ERROR 状态、没有行为的装饰按钮 |
| 深青整框 | 仅作为抽取漆纹或九宫格角件的母版 | 不可把完整长宽比图直接铺进可变尺寸容器 | Masthead、Catalog 或正文的整张背景 |

任何素材在 `forced-colors` 下必须退化为文字、原生边界、位置和状态名称；素材不能是理解或操作的必要条件。

## 4. 素材预处理门禁

在 CSS 引用前，每个素材必须先完成与用途对应的预处理，并以新文件名保存，不覆盖用户原始输入：

1. **透明图标与云水纹**：只裁去透明留白，保留原始 alpha；不得把黑色预览底色写入网页。
2. **金瓦**：输出 `left-cap`、可横向重复的 `middle-tile`、`right-cap` 三件构件；禁止
   `background-size: 100% auto` 拉伸完整金瓦横条。
3. **朱红操作面**：输出四角、四边和中心填充，或等价的无失真 `border-image`；任意 44px 以上命中区
   不得因图像缩放失真。
4. **深青框**：只提取无角饰的中部漆纹，或者以不带 `fill` 的九宫格边界使用；不得把完整框图覆盖内容层。
5. **宣纸**：使用真实纸浆纹理，不额外叠规则网格、噪点阵列或“雾化”滤镜。

素材预处理通过视觉检查后才可以进入 `web/public/textures/`。无文字、本地、同源、可追溯是必要条件，
但不能替代浏览器验收。

## 5. 施工切片

### A. 清理候选并建立无装饰骨架

- 停止继续追加全局 override；整理 Catalog 和共享壳层的 CSS 所有权。
- 移除完整框图、完整金瓦横条和工具条重复外框。
- 仅用色块、排版、细分隔线与真实数据实现第 2 节顺序。
- 在 `1440x960`、`1024x768`、`390x844`、`360x800` 检查无横向溢出、长 Run ID、按钮文字、状态和焦点。

本切片的退出条件是“即使关闭所有装饰图片，Catalog 仍是一张清楚的工作账册”。

### B. 基础材质与导航

- 只引入宣纸、深青漆纹、四枚导航图标与一次中轴饰件。
- 云水纹放在导航文字下方的净空区，透明度由真实文字对比度决定，不能压住入口文字。
- 验证四项按钮的 Tab、方向键、Home/End、URL/history 和焦点行为未发生变化。

本切片的退出条件是“素材帮助辨认层级，但移除后仍不损失导航和状态含义”。

### C. 单一一级门槛与真实导入操作

- 只有经过三段适配的金瓦才能进入一个一级门槛；同一首屏不得出现第二条同权重金瓦。
- 朱红操作面只包裹真实本地文件入口，不能改变其原生 label/input 关系、隐私语义或键盘焦点。
- 先用最窄桌面与最窄移动宽度检查素材端部、文字换行和触控尺寸，再检查 1440px 构图。

本切片的退出条件是“构件看起来属于结构本身，而不是压在结构表面的图片”。

### D. 实际浏览器复核

- 重新执行 Workbench tests、lint、type-check 与生产构建。
- 在回环只读 Catalog 上走正向、负向、损坏、本地导入、Catalog 行进入与返回焦点路径。
- 检查 Console、page error、request failure、同源 GET/HEAD、根溢出、资源载入和服务清理。
- 用户以内置浏览器审阅桌面与移动实际页面；审美否决即退回对应切片，不以截图或计划替代事实。

## 6. 明确停止条件

出现下列任一情况，停止本合同的实现并记录失败事实：

- 为了做视觉效果而改变 Schema、Verdict、Catalog/API、导入、URL、键盘或焦点语义；
- 任何区域重新形成“外框 -> 中框 -> 子卡片”三层结构；
- 需要用整张参考图、带文字图、远程图片、CDN 或水印素材掩盖布局问题；
- 金瓦、云水、深青框的作用不能用唯一职责解释；
- 真正的长文本、失败状态、移动宽度或 forced-colors 下发生遮挡、歧义、溢出或不可操作。
